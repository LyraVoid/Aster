# APD 第一批兼容改进

参考 FolkPatch main `29851e4875fa3b3834e58cfb027ed51720182ce8`。
本批只涉及终端错误处理、模块列表输出和管理器模块图标，不包含定制 KernelPatch、授权、启动阶段或挂载逻辑的移植。

## 终端与模块列表

- PTY 等待子进程时通过 Rust `last_os_error()` 读取错误，保留 EINTR 重试和退出状态处理，兼容 Android/Linux libc。
- 模块列表 JSON 输出遇到 BrokenPipe 时正常结束，其他写入错误仍返回失败。JSON 格式不变。

## 自定义操作图标

模块作者可在 `module.prop` 中填写相对于模块目录的路径：

```properties
actionIcon=icons/action.png
webuiIcon=icons/webui.webp
```

仅在原本具有操作脚本或 WebUI 的按钮上替换图标，不创建新入口、不更改按钮行为。
图标保留原色；未配置、读取失败或校验失败时使用内置图标。

约束：

- PNG、JPEG、WebP；文件最多 1 MiB，宽高各为 1–4096 像素。
- APD 不接受绝对路径、`..`、模块目录外的符号链接目标或非普通文件；不符合要求时从列表中删除对应图标字段。
- 管理器再次检查规范路径、文件大小、解码格式和尺寸。后台读取最多 1 MiB + 1 字节检测超限，按比例采样到最长边不超过 128 像素。
- 刷新模块列表会重新加载图标，支持替换同一路径的图片。
- 图标支持需要包含本批修改的 APD；旧 APD 返回相对路径时管理器会安全回退。

这些检查不构成针对持续恶意修改文件的 root 模块的隔离机制。

## 验证范围

Rust 测试覆盖正常输出、BrokenPipe、其他输出错误，以及图标相对路径、目录越界、符号链接、目录文件、缺失文件、超限文件和不支持格式。
Kotlin 测试覆盖路径过滤、尺寸边界及采样上限。实际图片解析由 Android BitmapFactory 完成，不能以 JVM 单元测试替代真机显示验证。
